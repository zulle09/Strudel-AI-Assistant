Start here

Hum into it with a real voice

Every transcription number so far comes from synthesized audio. A real voice is the one test that can overturn the tuning, and it takes fifteen minutes.

  1. Open the page in Safari or Chrome. Embedded previews block the microphone.
  2. Press the red dot, hum, press it again.
  3. Judge the panel labelled As hummed first. It involves no model.
uv run python app/server.py
# then open http://localhost:8000

For each take, note three things: did held notes shatter into repeats, did repeated notes merge into one, and was the tempo right, half or double.

_estimate_tempo's docstring says 19 of 21 realistic takes land within 10%, while the commit and docs/humming.md say 21 of 21. The melody.py docstring and the humming diagram still say tempo comes from beat_track. Nothing counts how often the beat_track fallback fires.

Independent of each other. Ordered by how soon they pay off.

08Donedone 15 Oct

Retry model calls with backoff

A rate limit used to fail the whole request after two quick attempts. The hum endpoint still returned its transcription, but the chat endpoint returned only an error.

Result
The chat model now allows 5 retries with exponential backoff, about 15 seconds of waiting. An out-of-credits error now says so instead of calling it a rate limit. The retry path itself is untested, because it needs a real 429.
09Closedclosed 15 Oct

Build the agent once

run_llm builds a new agent on every request. Measured: that takes about 1.2 ms (max 2.7 ms over 20 builds), against roughly 10 s for the model call.

Result
Not worth changing. The comments and docs that called it wasteful are corrected. Revisit only if the ratio changes.
10Hand offmedium

Keep a warm sandbox

Every validation starts Node and imports Strudel from scratch, and a correction loop pays that two or three times per answer.

Trade-off
A long-lived worker gives up per-request isolation. Restart it every few dozen patterns and after any timeout, and keep the same permission flags.
Done when
Validation latency is measured before and after, and the file-write, network and subprocess escapes still fail inside the worker.
11Donedone 15 Oct

Say so when the sandbox is missing

If node is not on the path or sandbox/node_modules is missing, the tool tells the agent to answer unverified and the server used to log nothing.

Result
core.py prints a "Pattern validator disabled" warning once at startup, and the validator and the warning share one check. Verified by temporarily moving node_modules aside.

Ideas

Worth exploring, not yet worth planning

28 · Lyrics from audio

Record or attach audio and ask about the lyrics. Needs a speech-to-text step, because today the agent never hears the audio and /api/chat takes text only. The text would feed the chat flow beside the melody summary.

29 · Spoken instructions

Audio models failed at pitch, but transcribing words is what they are good at. Saying "make it darker" is a natural gesture. Shares the speech-to-text step with 28.

30 · Chords and harmony

The pipeline is monophonic. A polyphonic transcriber such as Spotify's basic-pitch could add harmony, if its dependencies install on Python 3.13.

31 · Swing and triplets

The grid is straight sixteenth notes, so a shuffle is forced onto the nearest step.

32 · A native app again

The Capacitor shell was removed on 14 October to focus on the web app. It is recoverable from git history (2d88161) and only makes sense once the backend has a deployment target.

33 · Measure it in use

LangSmith tracing is already wired through environment variables, but nothing records latency, tool calls per answer, or how often validation changes the model's pattern.

Grounded in the code at commit 9d5bb31 plus the model switch. For how the pieces fit together, see docs/architecture.md.
