Start here

Hum into it before anything else

Every transcription number so far comes from synthesized audio. A real voice is the one test that can overturn the tuning, and it takes fifteen minutes.

  1. Open the page in Safari or Chrome. Embedded previews block the microphone.
  2. Press the red dot, hum, press it again.
  3. Judge the panel labelled As hummed first. It involves no model.
uv run python app/server.py
# then open http://localhost:8000

For each take, note three things: did held notes shatter into repeats, did repeated notes merge into one, and was the tempo right, half or double.

03Youan afternoon, mostly download

Build the iOS app

The Capacitor shell is scaffolded and its patcher was verified against the real template, but nothing has run on a device. Building needs the full Xcode app, not just the command line tools.

brew install cocoapods
cd mobile && npm install
STRUDEL_API_BASE=http://YOUR_MAC_IP:8000 npm run sync
npx cap add ios
node configure-ios.mjs
npx cap open ios

The server binds to localhost only, so for a phone start it this way instead, until 05 makes it a setting:

uv run uvicorn server:app --app-dir app --host 0.0.0.0 --port 8000
Done when
The app launches on your phone and shows the page.
Needs
Xcode from the App Store, and the phone on the same network as the Mac.
04You30 min

Test it on a device

Five behaviours were written for iOS and can only be seen on real hardware.

  • The microphone prompt appears and gives the reason.
  • Patterns still play with the silent switch on.
  • After a recording, sound stays on the loudspeaker instead of moving to the earpiece.
  • The top bar clears the Dynamic Island, and the composer clears the home indicator.
  • The phone reaches the Mac over the local network.
Done when
All five hold, or each failure comes back with what you saw.

08Hand offsmall to medium

Align the two Strudel versions

The page plays with @strudel/web 1.3.0, and the sandbox validates with @strudel/core 1.2.6, the newest core on npm. A function that exists in only one of them is judged by the other.

How
Find which core release the page's bundle contains. Then pin the page to a release that matches the sandbox, or run the sandbox on the page's own bundle if it will load in Node.
Done when
Both sides report the same version, and a test fails if they ever diverge.
09Hand offsmall

Check sound names against the real sample list

The validator flags gm_ soundfonts by prefix only. An invented drum name passes validation and then plays silence.

How
Fetch the dirt-samples sample map once, at install time, and ship it with the sandbox. The sandbox itself has no network, by design, so it cannot fetch the list when it runs.
Done when
A pattern using sound("bdd") comes back with a warning naming the unknown sound.
10Hand offsmall

Fix tempo in one click

Half- and double-time readings are inherent to hearing a pulse. Correcting one today means editing the setcpm line by hand.

How
Add ×2 and ÷2 controls to the As hummed panel that rewrite setcpm and replay.
Done when
A take read at half tempo can be corrected without typing.
11Hand offsmall

Retry model calls with backoff

Benchmarking tripped OpenAI's rate limit, and every request failed until it cleared. The hum endpoint still returned its transcription; the chat endpoint returned only an error.

Done when
A rate-limited call is retried with exponential backoff before anyone sees an error.
12Hand offsmall

Build the agent once

run_llm builds a new agent on every request, rebuilding its graph each time.

Done when
One agent is built at startup and reused, with latency measured before and after.
13Hand offmedium

Keep a warm sandbox

Every validation starts Node and imports Strudel from scratch, and a correction loop pays that two or three times per answer.

Trade-off
A long-lived worker gives up per-request isolation. Restart it every few dozen patterns and after any timeout, and keep the same permission flags.
Done when
Validation latency is measured before and after, and the file-write, network and subprocess escapes still fail inside the worker.
14Hand offsmall

Support the Responses API

gpt-6-astra and gpt-5.6-sol reject function tools on Chat Completions, and their replies arrive as content blocks that run_llm and the server treat as strings.

Done when
Both run through the full pipeline. Re-benchmark before switching, since neither beat gpt-5.4-mini on this task.

16Youa conversation with a lawyer

Get the AGPL question answered

Strudel is AGPL-3.0. The sandbox runs it inside a networked service, which is the case the licence's network clause addresses, and App Store terms are widely held to conflict with GPL-family licences.

Done when
You know what source you must publish, and whether the App Store is viable or TestFlight and the web are the route.
17Hand offsmall

Stop Pinecone drifting from the chunk dump

Ingestion overwrites chunks.json but upserts vectors, so a changed chunk leaves its old vector behind to keep surfacing in results.

Done when
Ingestion deletes vector ids that no longer appear in chunks.json.

Ideas

Worth exploring, not yet worth planning

Spoken instructions

Audio models failed at pitch, but transcribing words is what they are good at. Saying "make it darker" is a natural gesture on a phone.

Chords and harmony

The pipeline is monophonic. A polyphonic transcriber such as Spotify's basic-pitch could add harmony, if its dependencies install on Python 3.13.

Swing and triplets

The grid is straight sixteenth notes, so a shuffle is forced onto the nearest step.

Measure it in use

LangSmith tracing is already wired through environment variables, but nothing records latency, tool calls per answer, or how often validation changes the model's pattern.
